# دفع تلقائي — تطبيق أندرويد المرافق للموقع

يلتقط رسائل استلام الأموال (فودافون كاش، أورنج، WE، e&، إنستا باي…) على **هاتف صاحب الموقع** ويرسلها فور وصولها إلى `api/payment-hook.php`.
الموقع يطابق الرسالة مع طلب العميل **برقم المحفظة المحوَّل منها + المبلغ** (أو برقم العملية) ويضيف الرصيد تلقائياً.

> **غير مجرَّب:** لم يُبنَ هذا الإصدار ولم يُشغَّل (لا Android SDK ولا PHP في بيئة الكتابة). جرّبه على هاتف وموقع تجريبي قبل الاعتماد عليه.

## الجديد في 2.0
* الاسم **دفع تلقائي**، وصفحة **المطور أحمد محمد ابراهيم** داخل التطبيق (زر في الشاشة الرئيسية).
* **إرسال فوري**: كل رسالة تُرسل في لحظة وصولها بخيط مستقل (عدة رسائل معاً تُرسل بالتوازي). إن فشل الإرسال يتولاه العامل الاحتياطي (حتى 30 محاولة).
* بصمة الرسالة تشمل وقتها، فلا تُحذف رسالتان متشابهتان من عميلين مختلفين، وتُتجاهل إعادة الإرسال لنفس الرسالة.

## البناء على جيت هب
1. أنشئ مستودعاً خاصاً وارفع محتويات هذا المجلد.
2. **Actions ← Build APK ← Run workflow**، ثم نزّل `AutoPay-apk` وثبّت `app-debug.apk`.

## الإعداد على الهاتف
1. الصق **رابط الهوك** `https://موقعك/api/payment-hook.php` و**السر** من لوحة الإدارة > Auto-pay.
2. **المرسلون** (اختياري) مثل `VF-Cash`، و**الكلمات** لمنع إرسال رموز OTP.
3. **السماح بقراءة الرسائل** (أندرويد 13+: إعدادات التطبيق ← ⋮ ← السماح بالإعدادات المقيّدة).
4. **استثناء من توفير البطارية** + التشغيل التلقائي (شاومي/أوبو/هواوي).
5. **إرسال رسالة اختبار** وراقب "آخر العمليات".

## تفعيل المطابقة بالرقم والمبلغ (بدون رقم عملية)
في الإدارة ← طرق الدفع ← الطريقة: فعّل **auto_sms** واجعل حقلي **رقم الهاتف** و**المبلغ** "مطلوب"، وحقل رقم العملية "مخفي".
